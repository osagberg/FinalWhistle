# `.claude/bootstrap/` — one-shot project setup data

This folder is consumed by the `/bootstrap` slash command. After `/bootstrap` has successfully run once, this folder can be deleted.

## Files

- `INTAKE.md` — questionnaire Claude walks the user through
- `CUSTOMIZATION.md` — rules for mapping intake answers to template-file edits
- `INSTALLABLES.md` — catalog of every MCP / plugin / skill / package + install commands
- `PROFILES.md` — 5 reference profiles (narrative-heavy, action-character, puzzle-minimal, sim-management, vn-heavy) + matching algorithm
- `scripts/verify.sh` — post-bootstrap verification (runs grep for remaining placeholders, checks hooks executable, etc.)
- `scripts/install-plugins.txt` — generated by bootstrap; list of `/plugin install X` commands for user to paste

## Lifecycle

1. `/bootstrap` runs (once) — reads this folder, executes customization + installs
2. Bootstrap completes — folder contents are now historical
3. Optional: `rm -rf .claude/bootstrap/` to clean up (~100KB)
4. Optional: `rm .claude/commands/bootstrap.md` (one-shot command no longer needed)

Keeping this folder around has one benefit: if you want to re-customize mid-project (rare — scope shifts are better handled via `/log-decision` + targeted file edits), the reference data is still available.

## Do NOT edit during normal development

Normal development uses:
- `/next` / `/done` / `/audit` / `/refresh-docs` / `/log-decision` / `/status`

The bootstrap flow is a one-shot. If a template file turns out wrong, edit it directly — don't re-run bootstrap.

## Can I run `/bootstrap` again?

Not cleanly. The command is designed for empty fresh-copy-of-templates state. Running it on a partially-developed project will either:
- Do nothing useful (customizations already applied, MCPs already installed)
- Prompt you through intake again, then try to overwrite files you've edited

If you genuinely need to reset:
1. `git reset --hard <pre-bootstrap commit>`
2. Re-run `/bootstrap`

Or just edit the files directly to reflect new decisions.
